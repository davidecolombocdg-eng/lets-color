# Let's Color - Vercel Ready

App web per colorare e abbinare i pennarelli Ohuhu Honolulu B alle pagine da colorare.

## Come fare il deploy su Vercel (Gratis in 2 minuti):

1. Vai su [Vercel](https://vercel.com) e accedi con GitHub (o registrati).
2. Clicca su **Add New...** -> **Project**.
3. Carica questo progetto (puoi fare push della cartella su un repo GitHub privato/pubblico, oppure usare Vercel CLI).
4. Nella schermata di configurazione del progetto, apri **Environment Variables** e aggiungi:
   - **Key**: `GEMINI_API_KEY`
   - **Value**: *la tua chiave API di Google AI Studio*
5. Clicca su **Deploy**.

Fatto! Otterrai un URL pubblico sicuro (es. `https://lets-color.vercel.app`) dove tua moglie e tuo fratello potranno usarlo senza dover inserire nessuna chiave API.
